# Exercism C Solutions by Aman K Dev 081

This repository contains my finalized, test-driven solutions to the C programming track on Exercism.

## Overview
As part of my journey in systems programming and computer science, I am working through these exercises to build deep muscle memory in:
* Low-level memory management and pointer arithmetic.
* Bitwise operations and data dependencies.
* Idiomatic C design patterns.
* Test-driven development (TDD) principles.

## Development Environment
All solutions are written and verified locally using:
* **OS:** Windows Subsystem for Linux (WSL) - Ubuntu
* **Compiler:** GCC
* **Editor:** Visual Studio Code

## Structure (The Flat Pair Layout)
To maximize readability while maintaining strict C standards, solutions are organized as flat pairs directly in the root directory. Each challenge includes:
* A `.h` header file containing the standard includes, unique include guards, and function prototypes (interface).
* A `.c` source file containing the core algorithmic logic (implementation).
